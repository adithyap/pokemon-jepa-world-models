# Papers and Sources

| Source | Link | Key claim | Dataset/code | Relevance |
| --- | --- | --- | --- | --- |
| Causal-JEPA: Learning World Models through Object-Level Latent Interventions | https://arxiv.org/abs/2602.11389 | Object-level masking in latent prediction encourages relational and counterfactual interaction reasoning. | Code reported at https://github.com/galilai-group/cjepa | Strongest conceptual match for Pokemon teams, chess pieces, and battle/board object interactions. |
| TD-JEPA: Latent-predictive Representations for Zero-Shot Reinforcement Learning | https://huggingface.co/papers/2510.00739 | Temporal-difference latent prediction can learn long-term dynamics from offline transitions. | Paper source; offline RL framing. | Useful for predicting multi-turn consequences in chess or Pokemon without supervised reward labels. |
| seq-JEPA: Autoregressive Predictive Learning of Invariant-Equivariant World Models | https://arxiv.org/abs/2505.03176 | Sequential JEPA separates invariant and equivariant representations with autoregressive latent prediction. | Paper source. | Useful template for ordered move/state sequences and probing which latents retain tactical detail. |
| RLVR-World: Training World Models with Reinforcement Learning | https://huggingface.co/papers/2505.13934 | Verifiable rewards can align world-model training with transition quality rather than likelihood alone. | Paper source. | A possible second-stage idea using exact chess legality or Pokemon parser consistency as verifiable rewards. |
| Lichess Open Database | https://database.lichess.org/ | Lichess releases game, puzzle, and evaluation exports; game exports are CC0 and evaluations are JSONL. | CC0 games; evaluation file updated 2026-05-02. | Best public chess source, but must stream/subset aggressively. |
| `Lichess/standard-chess-games` | https://huggingface.co/datasets/Lichess/standard-chess-games | Hugging Face mirror of billions of rated standard games, updated monthly. | 7B+ rows; 4.94 TB, stream only. | Good for large-scale future validation, too large for local full-corpus experiments. |
| `cetusian/chess-sft-lichess-2200` | https://huggingface.co/datasets/cetusian/chess-sft-lichess-2200 | 200k strong-player Lichess positions with PGN prefix to next move. | 52.7 MB, CC0 derivative. | Manageable chess subset for local probing and next-move linear heads. |
| `Lichess/chess-position-evaluations` / open database evals | https://database.lichess.org/#evals | Stockfish position evaluations provide dense state-value targets. | JSONL zstd; hundreds of millions of positions. | Strong target for whether JEPA latents encode board value beyond next-move imitation. |
| `milkkarten/pokemon-showdown-replays-merged` | https://huggingface.co/datasets/milkkarten/pokemon-showdown-replays-merged | Merged Pokemon Showdown public replay dataset with 29M replays and streaming usage. | 38.7 GB; fields include `format`, `players`, `rating`, `log`, `turns`, `source`. | Best Pokemon source for streaming, format filtering, and offline transition extraction. |
| `HolidayOugi/pokemon-showdown-replays` | https://huggingface.co/datasets/HolidayOugi/pokemon-showdown-replays | Large public replay collection across generations/formats, updated in May 2026. | Hugging Face dataset, multiple formats. | Alternative Pokemon source if merged dataset schema or license notes are insufficient. |
| Pokemon Showdown Battles - Gen9 Randbats | https://www.kaggle.com/datasets/thephilliplin/pokemon-showdown-battles-gen9-randbats | 13k+ parsed Gen 9 random battle replay logs with MIT license. | Kaggle JSON files. | Lower-scale but easier parsed starting point for object-state extraction. |
